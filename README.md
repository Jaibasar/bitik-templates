# Бітік — баспаға дайын бет шаблондары

Қазақ тіліндегі кітаптарды 4 стандартты өлшемде баспаға дайын PDF-ке
айналдыратын XeLaTeX шаблон жүйесі.

## Қолдау көрсетілетін өлшемдер

| Файл | Өлшем | Сипаттама |
|---|---|---|
| `sizes/a4.tex` | 210×297мм | Стандартты A4 |
| `sizes/a5.tex` | 148×210мм | Стандартты A5 |
| `sizes/kdp-6x9.tex` | 152×229мм | Amazon KDP стандарты |
| `sizes/five-by-eight.tex` | 127×203мм | 5×8 дюйм (шағын форматты кітап) |

Дайын сынақ PDF-тер `samples/` қалтасында жатыр.

## Орнату (бір рет)

Қаріптерді жүйеге орнатудың қажеті жоқ — `bitik-core.tex` оларды
`fonts/` қапшығынан тікелей жүктейді (2026-09 жаңартуы, төменде
қараңыз). Тек қазақша тасымалдау (hyphenation) үлгісін бір рет
тіркеу керек — ол LaTeX деңгейінде емес, TeX-тің өзінің форматына
құрастыру арқылы орнатылатын жүйелік мүмкіндік, сондықтан оны
айналып өту мүмкін емес:

```bash
bash setup.sh
```

Бұл скрипт мыналарды істейді:
1. hyph-utf8 жобасынан қазақша тасымалдау үлгісін (hyph-kk.tex,
   2026 ақпанда шыққан) жүктеп, texmf-local ағашына орнатады
2. `language.dat`-қа `kazakh` тілін тіркейді
3. XeLaTeX форматын осы жаңа тілмен қайта құрастырады

Қолмен де істеуге болады — әр қадам скрипттің ішінде түсіндірмемен
жазылған.

**Ескерту:** соңғы қадам (`fmtutil-sys`) жүйелік TeX орнатуын
өзгертеді — ортақ серверде іске қосар алдында әкімшілік рұқсатын
тексеріңіз. Бұл қадам жоқ болса да шаблон компиляцияланады, тек
сөздер жол соңында бөлінбейді (тасымалдаусыз).

## Пайдалану

```bash
cd sizes
xelatex five-by-eight.tex   # немесе a4.tex / a5.tex / kdp-6x9.tex
```

Автордың мәтінін қосу үшін екі жол бар:
- жоба түбіріндегі `sample-text.tex` файлының ішін өз мәтініңізге
  ауыстырыңыз, немесе
- `sizes/*.tex` файлдарының кез келгеніне
  `\def\booktextfile{../menin-kitabym.tex}` жолын
  `\input{../bitik-core.tex}`-тен БҰРЫН қосып, өз файлыңыздың атын
  беріңіз.

## Әр өлшем файлының параметрлері

Әр `sizes/*.tex` файлы мына айнымалыларды анықтайды да,
`bitik-core.tex`-ті шақырады:

- `\trimwidth`, `\trimheight` — бет өлшемі (мм)
- `\margintop`, `\marginbottom`, `\margininside`, `\marginoutside` — жиектер (мм)
- `\basefontsize` — негізгі мәтін өлшемі (pt)
- `\baselinestretchval` — жол аралығы коэффициенті
- `\booktitle`, `\bookauthor` — метадеректер

Жаңа өлшем қосу үшін осы 8 айнымалысы бар жаңа файл жасап,
`\input{../bitik-core.tex}` жеткілікті.

## Тасымалдау (hyphenation) — шешілді

2026 жылдың ақпан айында TeX-тің hyph-utf8 пакетіне қазақ тілінің
ресми тасымалдау үлгісі қосылды. Бабель мен Полиглоссияда әлі
"kazakh" тілі ретінде танылмайды (тіл модулі жазылмаған), сондықтан
шаблон оны төмен деңгейде — `\language=\l@kazakh` арқылы — тікелей
таңдайды (`bitik-core.tex` ішінде, `setup.sh` тілді тіркегеннен
кейін ғана жұмыс істейді).

Нәтиже: сөздер жол соңында дұрыс дефиспен бөлінеді (мыс.
"жү-регінде", "бел-гілердің"). Бұл нақты сынақтан өтті — тар бағанда
("жүрегінде", "қорғандастырушыларыныкідей" сияқты ұзын сөздермен)
шаблон дұрыс тасымалдап шығарды.

**2026 мамырда** ресми `babel-kazakh` пакеті де шықты
(`\usepackage[kazakh]{babel}`), бірақ ол әлі көптеген TeX
дистрибутивтерінде толық интеграцияланбаған (тіл атауы babel-дің
ішкі каталогына қосылмаған) — сынақта `nil.ldf`-ке құлап, тасымалдау
мүлде істемей қалды. Сондықтан бұл шаблон әдейі төменгі деңгейлі
`\language=\l@kazakh` тәсілін ұстанады — ол нақты тексерілген және
жұмыс істейді.

## 2026-09 жаңартуы (тексеру нәтижесі)

Барлық 4 өлшем нақты xelatex-пен қайта компиляцияланып, PDF-тер
көзбен тексерілді. Түзетілгендер:

- **Қаріп жүктеу:** `bitik-core.tex` енді `PT Serif`-ті
  `fonts/` қапшығынан `Path=` арқылы тікелей жүктейді — жүйеге
  орнатудың (`~/.fonts`, `fc-cache`) қажеті жоқ. Ілгеріде бұл
  міндетті деп жазылған болатын, бірақ бұл дұрыс емес екен —
  тексерілді.
- **Мәтін файлының жолы:** `sizes/` қалтасынан компиляцияланғанда
  `\input{sample-text.tex}` табылмай қалатын қате түзетілді
  (`\booktextfile` айнымалысы арқылы).
- **Тасымалдау:** `\language=\l@kazakh` тәсілі нақты тексерілді
  және жұмыс істейтіні расталды (жоғарыдағы бөлімді қараңыз).
