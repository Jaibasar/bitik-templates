# Бітік — баспаға дайын бет шаблондары

**Бітік** — қазақ тіліндегі кітаптарды баспаға дайын, кәсіби деңгейдегі
PDF-ке айналдыратын XeLaTeX негізіндегі шаблон жүйесі. Жүйе төрт
стандартты бет өлшемін қолдайды, қазақ тілінің барлық ерекше
әріптерін дұрыс көрсетеді және сөздерді жол соңында дұрыс тасымалдайды.

## Мүмкіндіктер

- Төрт стандартты баспа өлшемі (A4, A5, Amazon KDP 6×9, 5×8 дюйм)
- Қазақ тілінің 9 арнайы әрпіне (Ә, І, Ң, Ғ, Ү, Ұ, Қ, Ө, Һ) толық
  қолдау — glyph жабуы мен диакритика тураланымы тексерілген
- Дұрыс жол соңы тасымалдауы (hyphenation) — қазақша мәтіндер үшін
  ерекше конфигурацияланған
- Қаріптер жобаның өз ішінде тасымалданады — жүйеге бөлек орнатудың
  қажеті жоқ
- Жеңіл параметрлендірілген құрылым — жаңа бет өлшемін бірнеше
  айнымалы арқылы қосуға болады

## Жоба құрылымы

```
bitik-templates/
├── bitik-core.tex     # Негізгі шаблон логикасы (бет пішімі, қаріп, стиль)
├── sample-text.tex    # Сынақ мәтін (өз мәтініңізбен алмастырылады)
├── setup.sh           # Қазақша тасымалдау үлгісін орнату скрипті
├── README.md          # Осы құжат
├── LICENSE.md         # Лицензиялық ақпарат
├── fonts/             # Жобаға енгізілген қаріптер (PT Serif, Noto Serif)
├── samples/           # Дайын сынақ PDF-тер (әр өлшем бойынша)
└── sizes/             # Әр бет өлшемінің конфигурация файлы
    ├── a4.tex
    ├── a5.tex
    ├── kdp-6x9.tex
    └── five-by-eight.tex
```

## Қолдау көрсетілетін өлшемдер

| Файл | Өлшем | Сипаттама |
|---|---|---|
| `sizes/a4.tex` | 210×297 мм | Стандартты A4 |
| `sizes/a5.tex` | 148×210 мм | Стандартты A5 |
| `sizes/kdp-6x9.tex` | 152×229 мм | Amazon KDP стандарты |
| `sizes/five-by-eight.tex` | 127×203 мм | 5×8 дюйм (шағын форматты кітап) |

Әр өлшемнің дайын сынақ PDF-і `samples/` қалтасында орналасқан.

## Талаптар

- XeLaTeX (TeX Live немесе MiKTeX құрамында келеді)
- `memoir`, `geometry`, `fontspec` LaTeX пакеттері (стандартты
  TeX Live дистрибутивінде бар)
- `bash` және `curl` — тек тасымалдау үлгісін орнату үшін
  (`setup.sh` скриптіне қажет)

## Орнату

Қаріптерді жүйеге орнатудың қажеті жоқ: `bitik-core.tex` оларды
`fonts/` қалтасынан тікелей жүктейді. Тек қазақша тасымалдау
(hyphenation) үлгісін бір рет тіркеу керек — бұл LaTeX деңгейінде
емес, TeX-тің өз форматына құрастыру арқылы орнатылатын жүйелік
мүмкіндік, сондықтан оны айналып өту мүмкін емес:

```bash
bash setup.sh
```

Скрипт мына қадамдарды орындайды:

1. hyph-utf8 жобасынан қазақша тасымалдау үлгісін (`hyph-kk.tex`)
   жүктеп, `texmf-local` ағашына орнатады
2. `language.dat` файлына `kazakh` тілін тіркейді
3. XeLaTeX форматын осы жаңа тілмен қайта құрастырады

Қажет болса, осы қадамдарды қолмен де орындауға болады — әрқайсысы
скрипт ішінде түсіндірмемен жазылған.

> **Ескерту:** соңғы қадам (`fmtutil-sys`) жүйелік TeX орнатуын
> өзгертеді, сондықтан ортақ серверде іске қосар алдында әкімшілік
> рұқсатыңызды тексеріңіз. Бұл қадам орындалмаса да шаблон
> компиляцияланады, тек сөздер жол соңында тасымалданбайды.

## Пайдалану

```bash
cd sizes
xelatex five-by-eight.tex   # немесе a4.tex / a5.tex / kdp-6x9.tex
```

Өз мәтініңізді қосудың екі жолы бар:

1. Жоба түбіріндегі `sample-text.tex` файлының мазмұнын өз
   мәтініңізбен алмастырыңыз, немесе
2. `sizes/*.tex` файлдарының кез келгеніне
   `\input{../bitik-core.tex}` жолынан **бұрын**
   `\def\booktextfile{../menin-kitabym.tex}` қосып, өз файлыңыздың
   атын көрсетіңіз.

## Параметрлер және баптау

Әр `sizes/*.tex` файлы төмендегі айнымалыларды анықтап, содан кейін
`bitik-core.tex` файлын шақырады:

| Айнымалы | Сипаттамасы |
|---|---|
| `\trimwidth`, `\trimheight` | Бет өлшемі (мм) |
| `\margintop`, `\marginbottom` | Жоғарғы/төменгі жиектер (мм) |
| `\margininside`, `\marginoutside` | Ішкі/сыртқы жиектер (мм) |
| `\basefontsize` | Негізгі мәтін өлшемі (pt) |
| `\baselinestretchval` | Жол аралығы коэффициенті |
| `\booktitle`, `\bookauthor` | Кітаптың атауы мен авторы |

Жаңа бет өлшемін қосу үшін осы айнымалылары бар жаңа файл жасап,
соңында `\input{../bitik-core.tex}` шақыру жеткілікті.

## Тасымалдау (hyphenation)

2026 жылдың ақпан айында TeX-тің `hyph-utf8` пакетіне қазақ тілінің
ресми тасымалдау үлгісі қосылды. Дегенмен, Babel мен Polyglossia
пакеттерінде әлі "kazakh" тілі үшін толық модуль жоқ, сондықтан бұл
шаблон тілді төмен деңгейде — `\language=\l@kazakh` арқылы — тікелей
таңдайды (`bitik-core.tex` ішінде; бұл тек `setup.sh` тілді
`language.dat`-қа тіркегеннен кейін ғана жұмыс істейді).

Бұл тәсіл сынақтан өткен: сөздер жол соңында дұрыс дефиспен бөлінеді
(мысалы, "жү-регінде", "бел-гілердің"), соның ішінде тар бағанда
ұзын сөздермен де.

2026 жылдың мамырында ресми `babel-kazakh` пакеті шықты
(`\usepackage[kazakh]{babel}`), бірақ ол көптеген TeX
дистрибутивтерінде әлі толық интеграцияланбаған. Сол себепті бұл
жоба әдейі төменгі деңгейлі `\language=\l@kazakh` тәсілін қолданады.

## Қаріп

Негізгі мәтін қарпі — **PT Serif** (ParaType, SIL Open Font
License). Қазақ тілінің барлық 9 арнайы әрпі (Ә, І, Ң, Ғ, Ү, Ұ, Қ,
Ө, Һ) тексерілген: толық glyph жабуы бар және диакритикалық
белгілердің тураланымы негізгі қаріппен үйлесімді.
